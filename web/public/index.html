    What troid does

    Computes both loss ceilings and reports the binding one. Sizes positions net of the 0.04%-per-side fee. Checks trades against firm rules — the hold limit (10 days for majors, 7 for other crypto, 5 for TradFi), the margin concentration limit, the five-day minimum. Works across the challenge types on troid's compare and every asset the firm lists.

    What it doesn't

    Publish trade signals. Place orders. Touch your credentials. Sell you a strategy.

    TROID.md is troid's rules and arithmetic as one file — paste it into any assistant as a system prompt. The MCP server does the same for Claude Desktop or Cursor, with exact arithmetic.

    Every figure here is arithmetic you can check. verify_claims.py in the repo re-derives each published number from first principles and tags it by confidence tier — derived, sourced, modelled, or measured. A measured number is never stated as fact.
